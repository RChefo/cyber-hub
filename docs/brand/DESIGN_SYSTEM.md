# ExploitX design system

The tokens and rules that make the app and the website look like one product. Brand and logo rules are in [BRAND_GUIDELINES.md](BRAND_GUIDELINES.md); the reasoning is in [VISUAL_IDENTITY.md](VISUAL_IDENTITY.md).

## Where the tokens live

| File | Role |
|---|---|
| `design/brand/build/tokens.mjs` | **The source.** Edit values here only |
| `design/brand/tokens.json`, `design/brand/tokens.css` | Generated by `node design/brand/build/build.mjs`. `tokens.css` defines every token as a `--ex-*` custom property on `:root` |
| `src/styles/index.css` (app) | Imports `tokens.css` and maps HeroUI's theme variables onto it (`--accent: var(--ex-uv-600)`, `--surface: var(--ex-surface)`, …). Tailwind utilities: `font-display`, `text-uv-300`, `bg-signal`, `bg-sev-*` |
| `website/src/styles.css` | Imports the same `tokens.css`. Its Tailwind theme (`--color-accent`, `--color-ink`, …) uses the same values |
| `src/modules/osint/graph/style.ts` (`THEME`) | The canvas graph and its SVG export cannot read CSS variables: they hold a copy of the values, with a comment pointing here |
| `src/components/brand/logoData.ts`, `website/src/components/brand/logoData.ts` | Generated logo geometry for the inline `BrandSymbol`, `Wordmark` and `Logo` components |

**Rule:** a colour in a component is a token or a Tailwind theme colour, not a new hex value. The exceptions are data encodings that carry meaning (entity types in graphs, which also have a glyph and a legend).

### Semantic and severity

| Token | Value | Use |
|---|---|---|
| `--ex-success` | `#3CC88F` | Success states |
| `--ex-warning` | `#E8A93A` | Warnings, items waiting for a decision |
| `--ex-error` | `#E5484D` | Errors, destructive actions |
| `--ex-info` | `#4C9BFF` | Information |
| `--ex-sev-critical` | `#E5484D` | Critical |
| `--ex-sev-high` | `#F2803A` | High |
| `--ex-sev-medium` | `#F2C94C` | Medium |
| `--ex-sev-low` | `#4C9BFF` | Low |
| `--ex-sev-info` | `#9AA3B5` | Informational |

* **Severity is never shown by colour alone.**
  * Badges carry the name ("High"), and CVSS badges the score.
  * Charts label each bar, and lists sort by severity.
  * Tinted backgrounds are 15 % of the colour, with the text in a lighter tint of it.
* **Ultraviolet is never a severity or a status.**

### Data visualisation

| Token | Values | Use |
|---|---|---|
| `--ex-viz-1…8` | `#7C6AFF` `#38C9B4` `#F2B33D` `#F0689C` `#4FA3FF` `#A6D94A` `#C58BFF` `#8E9AB0` | Categorical series in this order: threat categories, sources, timeline event kinds, chart series |
| `--ex-viz-seq-1…6` | `#1E2130` → `#C3BAFF` | Sequential: ATT&CK coverage, density, heat maps (low to high) |
| `--ex-viz-grid`, `--ex-viz-axis` | `rgba(255,255,255,.06)`, `#8B92A5` | Chart grid and axis labels |
| `--ex-viz-edge`, `--ex-viz-edge-active` | `#3B4054`, `#B4A9FF` | Graph relationships, at rest and selected |

**Rules.**
* **Severity charts use the severity scale**; other charts use the categorical palette.
* **Axis labels and data labels use text tokens,** never the series colour on its own.
* **Graph entities keep their established type colours, glyphs and legend** (`src/modules/osint/model.ts`, `src/modules/projects/investigation.ts`). Changing them would break the reading of saved graphs and exports.
* **Line identity** (verified, observed, inferred, disputed) is also drawn by dash style, not only by colour.

## Typography

| Token | Family | Use | Sizes in the app |
|---|---|---|---|
| `--ex-font-display` / `font-display` | Archivo Variable, `wdth` 106, 600 | Page titles (`PageHeader`), key figures (`Stat`), website headings | 23 px page title, 22 px figures |
| `--ex-font-sans` / `font-sans` | IBM Plex Sans 400/500/600 | Everything else | 14 px body, 13–13.5 px dense UI, 12–12.5 px labels, 15 px panel titles |
| `--ex-font-mono` / `font-mono` | JetBrains Mono Variable | Commands, identifiers, hashes, code | 12–13 px; ligatures off |

* **Numbers:** `.tabular` for every number that lines up.
* **Headings:** letter spacing −0.01 em on display headings; sentence case for titles and buttons.

## Space, radius, elevation, motion

* **Space:** a 4 px scale (`--ex-space-1` = 4 px … `--ex-space-12` = 48 px).
  * Panels have 16 px padding and a 12–14 px gap between panels.
  * Pages have 20–24 px margins.
* **Radius:**

  | Size | Value | Use |
  |---|---|---|
  | xs | 4 px | Chips |
  | sm | 6 px | Navigation items |
  | md | 8 px | Controls, fields (`--radius`) |
  | lg | 12 px | Panels |
  | xl | 16 px | Dialogs, frames |
  | full | — | Pills, avatars |
* **Elevation:** fills and shadows, from the background through panel-inset, surface and raised to overlay.
  * `--ex-shadow-surface` for panels, `--ex-shadow-overlay` for menus and dialogs.
  * **No outlines around cards, panels, rows or nested components.**
* **Motion:** `--ex-motion-fast` 120 ms, `--ex-motion-base` 200 ms, `--ex-motion-slow` 320 ms, with `--ex-motion-ease`.
  * Motion explains a change (open, close, reorder); it is never decoration.
  * `prefers-reduced-motion` turns transitions and animations off (app: `index.css`; website: `gsap.matchMedia()`).

## Interaction states

| State | Rule |
|---|---|
| Hover | One step up in surface (`--surface-hover`, `--default-hover`); solid Ultraviolet buttons go one step **deeper** (`#5E4BEA`) so white text stays above 4.5:1 |
| Focus (keyboard) | A 2 px ring in Ultraviolet 500, always visible, never removed |
| Selected / current | Ultraviolet indicator (the 2 px bar in navigation, the selected tab's fill) plus `aria-current` / `aria-selected` |
| Disabled | Faint text, no hover; the reason in a tooltip where it is not obvious |
| Invalid | The field's red stroke and the message under it (`--field-border-invalid`) |
| Loading | Skeleton rows (`LoadingRows`) for content, an inline spinner for actions; never a full-screen spinner |
| Empty | `EmptyBlock`: an icon, what is missing, and the next action |
| Error | `ErrorBlock` / an alert with what failed and what to do; a **Retry** when it can succeed later |

## Logo in the interface

* **Sidebar:**
  * expanded: `<Logo capHeight={12.5} />`, with the descriptor "Security research platform" in muted text;
  * collapsed: `<BrandSymbol height={22} />` (the small version without the gap).
* **Website header and footer:** `<Logo capHeight={15} />`. The hero eyebrow is a 14 px symbol.
* The symbol's target chevron and the wordmark take `currentColor`, so they follow the text colour. The operator's chevron is always `var(--ex-uv-500)`.

## Checklist for a new screen

* [ ] Colours come from tokens or theme utilities; no new hex values.
* [ ] No borders around containers; separation by fill, shadow and space.
* [ ] One primary (Ultraviolet) action per view.
* [ ] Every severity shows its name; charts have labels.
* [ ] Numbers that line up use `.tabular`.
* [ ] Empty, loading and error states exist, and say what to do next.
* [ ] Keyboard focus is visible; motion respects `prefers-reduced-motion`.
* [ ] It works at 800 × 480 (the smallest window) and at 200 % scaling (the layout probe in `scripts/qa/`).
