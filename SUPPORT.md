# Getting help

ExploitX is maintained by its owner. There is no commercial support and no guaranteed response time, but questions and reports are welcome.

| You want to… | Go to |
|---|---|
| Ask how something works | First the documentation: the [README](README.md) and [docs/](docs/README.md). If that does not answer it, [open an issue with the *Question* form](https://github.com/RChefo/cyber-hub/issues/new/choose) |
| Report a bug | [Open an issue with the *Bug report* form](https://github.com/RChefo/cyber-hub/issues/new/choose). Please include the version, platform, installation format and the steps to reproduce |
| Suggest a feature or an improvement | [Open an issue with the *Feature request* form](https://github.com/RChefo/cyber-hub/issues/new/choose) |
| Report a security vulnerability | **Privately**, never in an issue: see [SECURITY.md](SECURITY.md) |
| Report behaviour that breaks the Code of Conduct | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), section "Enforcement" |
| Contribute code or documentation | See [CONTRIBUTING.md](CONTRIBUTING.md) |

GitHub Discussions are not enabled for this repository.

Before you open an issue:

* search the existing issues, including closed ones;
* check that you run the latest code or release candidate;
* remove credentials, tokens, personal data and data about third-party targets from logs, screenshots and files you attach. ExploitX's own data (projects, findings, evidence) can describe systems you assessed.
